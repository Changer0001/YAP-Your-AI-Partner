# POS Network Setup (ARCHIVED — 2024) — Property A — Downtown Hotel (SYNTHETIC)

> ⚠️ HISTORICAL / ARCHIVED document from 2024. Kept for reference. See the current change records
> and network overview for the up-to-date design.

In the 2024 build, POS terminals at the Downtown property were placed on **VLAN 50**
(subnet 10.20.50.0/24). DHCP for POS was served from the core switch.

This design was later replaced (see change record CHG-2041, 2026-03-01), which moved POS to VLAN 55.
